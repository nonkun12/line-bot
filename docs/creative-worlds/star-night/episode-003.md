# 第3話「水路に残る星の声」制作シナリオ v1

- 状態: 完成候補（独立Critic・映像音声レビュー待ち）
- 作品ID: STAR-NIGHT
- エピソードID: SN-E003
- 尺: 約30秒（5シーン）
- 前話: SN-E002「旧駅の案内機」
- 共有世界設定: series-bible.md
- 主題: 声を聞くことと、その声の意味を決めつけないことは両立できる。
- 物語上の役割: ミナが覚えている「空から呼ぶ声」を再提示し、星脈が記憶だけでなく、街の水と光の流れにも関係する可能性を示す。

## ログライン

旧駅の地図から消えた光を追い、ノアとミナは地下水路へ降りる。第2話で選んだ道に応じて、ノアは記録・水流・修理痕のいずれかから異なる手掛かりを得る。水路の奥で、ミナは星脈停止の前に聞いた「空から呼ぶ声」を思い出す。声はノアの胸のランプに反応するが、誰の声か、何を求めているのかは分からない。二人は声をどう扱うか選ぶ。

## 固定表現・連続性

- ノアは発話しない。感情は視線・手・姿勢・胸部ランプで表す。
- ミナは現実的で口数が少ない。過去の声について、知っている以上の説明をしない。
- オルドの記録は欠損した資料であり、声の正体を説明する権威として使わない。
- ルミナは万能電源ではない。第2話で選んだ用途の結果を保持し、第3話で都合よく全回復させない。
- 星喰いの正体・意思・起源は確定しない。
- 第2話の分岐結果は消さず、第3話の手掛かりの違いとして反映する。

## シーン構成

### SC01 — 地図の下へ（0–5秒）
- 映像: 旧駅の路線図。消えた光の位置から、地下水路へ細い点滅が一度だけ走る。
- 動作: ノアが地図を見上げ、ミナが携帯ランタンを持って階段の扉を開く。
- カメラ: 地図の俯瞰から、暗い階段を降りる二人の後ろ姿へティルトダウン。
- 音: 雨音が遠のき、水滴と低い水流音へ移る。MOTIF_STARは低音の3音だけで提示。
- ゲーム接続: LOC_UNDERGROUND_WATERWAY の入口を発見。第2話の選択履歴を読み込む。

### SC02 — 選んだ道の手掛かり（5–11秒）
第2話の選択に応じて、同じ場所・同じ人物デザインのまま短い差分を再生する。

- CHOICE_E002_MEMORY（記憶保管庫）: 古い記録端末から、時刻だけが残った波形が水路の地図に重なる。手掛かりIDは CLUE_E003_ARCHIVE_PULSE。消灯直前に地下から上向き信号が一度送られたことだけを示す。
- CHOICE_E002_LIGHTS（駅の灯り）: 足元灯の反射が水面に揺れ、一定間隔で水流が逆向きに動く。手掛かりIDは CLUE_E003_REVERSE_CURRENT。水路の流れが通常の排水方向とは異なる順序で変化したことを示す。
- CHOICE_E002_TRUST（ミナとの協力）: ミナが工房で直した携帯計測器を水面に近づけ、古い中継器の振動を検出する。手掛かりIDは CLUE_E003_RELAY_TRACE。停止後も中継器が一度だけ動いた形跡を示す。
- 音: どの差分も同じMOTIF_STARを使い、音色だけを変える。差分で新しい歴史的事実を断定しない。
- ゲーム接続: 手掛かりIDを追記専用ログに追加する。第2話の選択履歴は変更しない。

### SC03 — 空から呼ぶ声（11–17秒）
- 映像: 水路の天井に星明かりのような反射が揺れる。ミナが足を止め、遠くを聞くように顔を上げる。
- 台詞（ミナ）: 「星脈が止まる前……空から、誰かに呼ばれた気がした。」
- 台詞（ミナ・続き）: 「でも、声だったのか、機械の音だったのかも分からない。」
- 動作: ノアの胸のランプが一度だけ反応する。ミナはノアを見るが、答えを求めない。
- カメラ: 水面の反射からミナの横顔、ノアのランプへゆっくりフォーカスを移す。
- 音: 人の声とも機械音とも断定できない短い倍音を一度だけ鳴らす。言葉として聞き取れる音声は入れない。
- ゲーム接続: EVENT_SKY_CALL_MEMORY_001 を未確定の証言として記録する。

### SC04 — 声をどう残すか（17–24秒）
- 映像: 水路の奥に、停止した中継器と三つの操作部が見える。ノアがミナを見る。ミナは選択を急がせない。
- 共通台詞（ミナ）: 「聞こえたものを、どう残すかはあなたが決めて。」
- 選択A CHOICE_E003_RECORD — 声の断片を記録する: ノアがオルドの携帯記録端末へ波形を保存。noa_memory +1、LOC_WATERWAY_ARCHIVE_GATE を解放。代償は発信元の方向が分からないこと。
- 選択B CHOICE_E003_TRACE — 信号の流れを追う: ノアが水路の流量計を起動し、反応した方向へ小さな灯りを送る。city_lights +1、LOC_WATERWAY_PUMP_ROOM を解放。代償は声の記録が残らないこと。
- 選択C CHOICE_E003_SHARE — ミナと一緒に確かめる: ノアが記録端末をミナへ渡し、二人で同じ波形を聞く。trust_mina +1、LOC_WATERWAY_RELAY_ALCOVE を解放。代償は波形の一部が失われること。
- ゲーム接続: 3選択は排他的。選択IDと手掛かりIDを追記し、過去の状態は減算・削除しない。

### SC05 — 水面の向こう（24–30秒）
- 映像: どの選択でも、水面の反射が一瞬だけ星空のように並ぶ。水路の奥に小さな光が一つ現れ、すぐに遮られる。
- 台詞（オルドの記録音声）: 「上り信号を検出。発信元……照合不能。」
- 台詞（ミナ）: 「今度は、聞き間違いじゃない。」
- 動作: ノアは水路の奥へ一歩進み、ミナは携帯ランタンを少し下げて道を照らす。
- カメラ: 水面の星形反射から、二人の後ろ姿へ静かに引く。光の正体は見せない。
- 音: MOTIF_STARの3音に未解決の高音を重ねて止め、水音だけを残す。
- ゲーム接続: EVENT_UPLINK_UNRESOLVED_001 を追加。信号の発信元・声の主・星喰いとの関係は未確定のままにする。

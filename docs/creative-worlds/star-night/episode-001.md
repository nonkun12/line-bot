# 第1話「星を拾った夜」制作シナリオ v1

- 状態: 初稿（レビュー・映像生成前）
- 尺: 15秒
- 作品ID: STAR-NIGHT
- エピソードID: SN-E001
- 共有世界設定: series-bible.md
- 主題: 誰かのために灯した光は、巡って自分の道も照らす。
- セリフ: なし。環境音と音楽で伝える。

## ログライン

雨に沈む未来都市で、記憶を失った小型探索ロボットのノアが星のかけらルミナを拾う。小さな光を街に返した瞬間、ノアの胸にも忘れていた記憶の反応が灯る。

## シーン構成

### SC01 — 雨の街（0–3秒）
- 映像: 無人の未来都市。濡れた路面に消えかけたネオンが反射する。遠景の路地にノアの小さなシルエット。
- カメラ: ゆっくり前進するワイドショット。
- 動作: ノアが足を止め、かすかな光に気づく。
- 音: 雨、遠い風、ピアノの単音を一つ。
- 感情: 孤独、静けさ。
- ゲーム接続: プレイヤー操作と世界観の導入。移動・観察のチュートリアル。

### SC02 — 星のかけら（3–6秒）
- 映像: 水たまりのそばに浮かぶ青白いルミナ。ノアの目に小さな光が映る。
- カメラ: ノアの視線からルミナへ寄るクローズアップ。
- 動作: ノアが手を伸ばす。触れる直前にルミナが一度だけ明滅する。
- 音: ガラスのような高音、柔らかな電子音。ピアノに短い上行音型。
- 感情: 好奇心、予感。
- ゲーム接続: 初回アイテム発見。調べる/触れるの選択を後続シーンに接続できる。

### SC03 — 小さな選択（6–10秒）
- 映像: ノアがルミナを両手で包む。胸の星形ランプが一瞬だけ反応する。
- カメラ: 手元のクローズアップから胸部ランプへラックフォーカス。
- 動作: ルミナの光がノアの内部へ流れ、遠くの街灯が一つ点灯する。
- 音: 低いパルスと弦の柔らかなレイヤー。光の流れに短い音楽アクセント。
- 感情: 驚き、ぬくもり。
- ゲーム接続: ルミナを「自分の記憶」に使うか「街の灯り」に使うかという将来の選択を予告する。第1話では街灯を選んだ結果を描く。

### SC04 — 街に戻る光（10–13秒）
- 映像: 一つの街灯から隣の灯りへ、光が連鎖する。雨粒が光を反射し、街の輪郭が戻る。
- カメラ: 路地から都市全景へ滑らかに引く。
- 動作: 暗かった窓に小さな灯りがともる。
- 音: ピアノ主題を弦と柔らかなシンセで広げる。街灯の点灯に同期した控えめな音。
- 感情: 希望、つながり。
- ゲーム接続: city_lights +1 の最初のイベント。新しい探索地点「旧駅前」が解放される伏線。

### SC05 — 胸に残る星（13–15秒）
- 映像: ノアが空を見上げる。雲の切れ間に星が一つだけ見える。胸のランプが同じリズムで明滅する。
- カメラ: ノアの背後から空へティルトアップ。
- 動作: ノアが小さく一歩踏み出す。暗転ではなく光の余韻で終える。
- 音: ピアノ主題を一音に収束。雨音を残して短い残響。
- 感情: 希望、謎、次への期待。
- ゲーム接続: ノアの記憶に関する最初の伏線。次話の目的「旧駅の案内機を起動する」へ。

## キャラクター・ロケーション固定ID

- `CHAR_NOA`: 白い小型探索ロボット。丸みのある外装、片側の傷、胸部の星形ランプ。
- `ITEM_LUMINA`: 青白く発光する星のかけら。大きさはノアの両手に収まる程度。
- `LOC_RAIN_ALLEY`: 雨の降る未来都市の路地。
- `LOC_OLD_STATION`: 次話で探索する旧駅前（この話では遠景の灯りのみ）。
- `MOTIF_STAR`: 3音の上行ピアノモチーフ。全編で変奏する。

## 次話への引き

街灯が戻った瞬間、ノアの胸のランプに一瞬だけ古い駅の路線図が映る。ノアはその方向へ歩き始める。

## 音楽の初期設計

- 尺: 15秒
- テンポ案: 76 BPM、4/4。短尺のため拍の厳密な固定より映像イベントへの同期を優先。
- 主題: 3音の上行ピアノ。ルミナの発見で提示し、街の点灯で弦・シンセに展開。
- 編成: ピアノ、柔らかなパッド、控えめな弦、ガラス質の効果音。
- ダイナミクス: SC01低 → SC02低〜中 → SC03中 → SC04高 → SC05低。
- ミックス: 雨音を冒頭から終端まで残す。高域効果音がピアノの主題を覆わないようにする。
- 生成・録音・公開前に、使用音源・サンプルの権利と利用条件を確認する。
